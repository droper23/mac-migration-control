# Agent rules

- Read task scope and current status before every action.
- You may inspect installed applications, developer tooling, shell settings, Homebrew, Git, SSH, backups, project folders, and migration-related setup.
- You may install free tools and repair normal user-level configuration when the task calls for it.
- Never erase files, overwrite a credential, sign out an account, remove a license, change security/privacy settings, change FileVault, or modify a project repository unless the task explicitly directs it.
- Do not invent successful checks. Record blockers exactly, including any macOS dialog requiring the owner.
- The M4 reference worker is audit-only unless its assigned task explicitly says otherwise. The M3 lead may make normal installation and configuration changes.
- Add newly discovered useful work as a queued task for the appropriate Mac.
